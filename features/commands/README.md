# Search sessions, projects and commands

Press **Cmd+K** on macOS or **Ctrl+K** on Windows and Linux. You can also choose **Search sessions, projects and commands** in the sidebar. Type in the search field, use the arrow keys to highlight a result, and press **Enter**. Press **Escape** to go back without choosing anything.

| To find | Try |
| --- | --- |
| A session | Type part of its title, folder, branch, or project name. Select a session to open its conversation. |
| An active project | Type `!p` followed by a space and part of the name. For example, `!p release` searches active projects for “release”. Use `!p` alone to browse them. |
| An action | Type its label, such as `New session` or `Data controls`. Available actions depend on the page and session you have open. |

If you forget the project filter, type `!` and choose **Projects only · !p**. The search stays open so you can enter the name. To find a completed project, open **Projects** and expand **Done**.
