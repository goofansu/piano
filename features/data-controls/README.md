# Archive and restore sessions

Archive a session when you want it out of your sidebar but may need its transcript again.

## Archive one session

Open the session's menu and choose **Archive**. If Pi is working, Piano asks you to confirm **Stop and archive**. Confirming interrupts that work and keeps the transcript. If you mean to remove the saved transcript permanently, use **Delete** and review its separate confirmation.

## Archive several sessions

Open **Settings → Data controls** and select **Archive all**. Review the number of eligible sessions before confirming. Pinned sessions and sessions where Pi is starting or running stay available, including sessions where Pi is idle and waiting for input.

## Restore a session

Under **Settings → Data controls → Archived sessions**, find the session by title and folder, then select **Unarchive**. You can reopen it at its original address. Restoring the session leaves Pi stopped and any closed folder stays closed.
