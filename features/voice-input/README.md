# Dictate a message

Turn on **Voice input** in **Settings → Preferences** and enter an OpenAI API key when prompted. For transcription, Piano sends the recording to OpenAI together with any available project, folder, branch, and session names.

1. Open a new or existing session and place the cursor where you want the text.
2. Select the microphone (**Voice input**) and allow microphone access in your browser.
3. Speak, then choose **Stop recording**. The transcribed text goes into the draft where you started.
4. Review or edit the words, then choose **Send** when ready.

You can cancel a pending transcription with **Cancel transcription**. Recording stops automatically at ten minutes. If a recording exceeds 25 MB, record a shorter message.

To change credentials, open **Voice input actions** in Preferences and choose **Replace key**. **Remove key** turns off dictation and removes the saved key from Piano. You can revoke the key separately at OpenAI.
