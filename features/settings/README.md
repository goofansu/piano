# Settings

Open **Settings** at the bottom of the sidebar. Choose a section from the list. Select **Home** when you’re ready to return to your work.

| Section | What you can do |
| --- | --- |
| Providers | Connect a model provider, manage API keys, or set up Radius. [Provider sign-in](../providers/README.md) · [Radius setup](../radius/README.md) |
| MCP | Connect a tool server and authorize access. [MCP setup](../mcp/README.md) |
| Skills | Give Pi reusable instructions for recurring tasks. [Create a skill](../library/README.md#create-and-use-a-skill) |
| Prompts | Save a message you can invoke with a slash command. [Create a prompt](../library/README.md#create-and-use-a-prompt) |
| Webhooks | Choose which session events to send to a receiver and test delivery. [Set up a webhook](../webhooks/README.md) |
| Preferences | Set up voice input so you can dictate a draft. [Voice input](../voice-input/README.md) |
| Data controls | Archive sessions in bulk or restore an archived session. [Archive and restore](../data-controls/README.md) |
