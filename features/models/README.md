# Choose a model and effort level

Select the model name beside the message box to open **Model and effort**. In a new session, select a directory first. The available models depend on your provider access and the directory you chose.

Search by provider or model name, select the model, then choose an effort level it supports. A choice on the new-session page applies when you send the first message. You can also open the picker in an existing session to change how Pi handles subsequent work.

- **Make default** saves the selected model and effort in Pi’s global settings for future sessions.
- **Use default** applies the saved model and effort to your current selection.

If a model you expect is missing, check your account in **Settings → Providers**, then choose **Refresh models** when available. After adding credentials, start a new session to use them.
