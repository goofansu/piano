# Navigate between sessions

Open the sidebar and select a session to return to its conversation. If the sidebar is hidden, use **Show sidebar**. Choose **New session** to start fresh, or **Projects** to see sessions grouped around a goal.

## Organize the sidebar

Open **View options** in the sidebar. Choose **Group by → Project** to see related sessions across repositories, **Folder** to find work in a checkout, or **Date** to browse by time. Under **Sort by**, choose **Activity** or **Name**.

To keep a session handy when you change the grouping, open its session menu and choose **Pin**. You can find it in **Pinned** and remove it from there with **Unpin**.

## Switch without leaving the keyboard

Use **Option+↑** or **Option+↓** on macOS, or **Alt+↑** or **Alt+↓** on Windows and Linux, to move to the previous or next session in sidebar order. The shortcuts follow expanded groups and skip unavailable sessions. You can use them while typing in the session composer.

To find a session outside the expanded groups, search for its title, folder, or branch in the [command palette](../commands/README.md).
