# Attach files

In a new or existing session, choose the paperclip (**Attach files**), drop files onto the composer,
or paste an image from your clipboard. Piano accepts PNG, JPEG, GIF, WebP, AutoCAD DWG, PDF, and UTF-8 plain text.
Source code, configuration, and extensionless files such as `Makefile` count as plain text.
You can send up to **10 files per message**, up to **10 MiB per file** and **50 MiB total**.
To remove a file before sending, select the remove button beside its name.

Images appear as thumbnails in the transcript. Select one to open it in a new tab. If you see
**Preview unavailable**, reopen the session to reload it.

Piano stores drawings, PDFs, and text files on the machine running Piano and includes the local
paths in your message. It does not render or run attached files, and it does not perform OCR.
Archive keeps these files; deleting the session deletes its stored copies.
