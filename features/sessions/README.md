# Start or continue a session

A session keeps a conversation with Pi together with the directory where Pi works. Reopen the session from the sidebar when you want to pick up the same task.

## Start a conversation

1. Choose **New session** and select the **Directory** where Pi should work.
2. To group the conversation with related work, choose a **Project**. You can also start the session from a project’s home page.
3. Write your first message and choose **Send**. You can [attach images](image-attachments.md) or [choose a model and effort level](../models/README.md) before sending.

## Send another message while Pi is working

Choose **steer** to give Pi a correction for its current task, or **follow-up** to queue work for after it finishes. You can put queued text back into the composer with **Edit** and revise it while Pi continues. If the connection drops during Edit or Stop, leave the tab open. When the same tab reconnects within a day, Piano returns the text Pi removed to that session’s draft. Reloading the page discards unsent drafts. Reattach any images before sending the edited message.

To interrupt Pi, choose **Stop** when the composer is empty. Stop moves any queued text to the draft. If Pi doesn't stop, Piano says so and Pi keeps working: press Esc in the message box, or clear the draft and choose **Stop** again. To answer a question from Pi, use the controls in the question itself.

## Recover a message

If you see **Could not start session**, your draft is available to edit. Choose **Retry** to send it again. If delivery is uncertain, look for the session in the sidebar and check its transcript and queue before sending another copy.

If Pi rejects a message, its text, quotes and images return to the composer. You can edit the draft and send it again when you’re ready.
